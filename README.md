# Artem Grigorets

I write about making content with AI, content automation and building a personal brand with AI at [grigorets.com](https://grigorets.com/about), and I build tools that let creators make more content in less time.

## What I make

- **[AI Editing Studio](https://grigorets.com/studio)** — a Claude Code skill (`/studio-edit`) that turns raw talking-head phone clips into a finished vertical Reel. It keeps the best take of every line, cuts dead air, cuts you out of the background so words sit behind your head, and adds captions, motion graphics and sound. Editing runs on your own Mac, Windows or Linux computer. Free download; Studio Pro is a paid edition. [Documentation](https://github.com/want1321/ai-editing-studio-docs) · [Setup guide](https://grigorets.com/studio/guide)
- **[Footage Sorter](https://github.com/want1321/footage-sorter)** — an open-source (MIT) Claude Code tool that sorts a folder of raw footage into Reels, Carousels/Posts, Stories and Tutorials.
